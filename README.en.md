## ✨ Features

- **mpv-powered** — Full format support with strong decoding capability
- **macOS-inspired** — Clean, elegant, frameless design
- **Windows-native** — DWM Acrylic blur transparency effect
- **Three-column layout** — Media library / Timeline / Independent playback window
- **Auto-play** — Resize window by double-clicking edges

## 📦 Installation

```bash
pip install -r requirements.txt
```

## 🚀 Run

```bash
python main.py
```
