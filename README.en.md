## ✨ Features

- **mpv-powered** — Full format support, hardware decoding, zero quality loss
- **macOS-inspired** — Clean, elegant, frameless design with Windows Acrylic blur
- **Smart playback** — Auto-advance to the next item; repeat one / loop list modes
- **External subtitles** — Auto-loads same-named subs; drop .srt / .ass to attach
- **On-video controls** — Double-click fullscreen, click to pause, wheel for volume, OSD feedback
- **Playback memory** — Resumes where you left off; remembers volume / speed / theme / playlist
- **Screenshot** — Save the current frame next to the video with one key

## ⌨️ Shortcuts

| Key | Action |
| --- | --- |
| Space | Play / pause |
| ← / → | Seek −5s / +5s |
| Ctrl+← / Ctrl+→ | Seek −30s / +30s |
| ↑ / ↓ | Volume ±5% |
| [ / ] | Speed −0.1x / +0.1x |
| L | Cycle loop mode |
| S | Screenshot |
| F / F11 | Fullscreen |
| M | Mute |
| Ctrl+O | Open files |
| Ctrl+I | Playlist |
| Delete | Remove selected |
| Esc | Exit fullscreen |
| Ctrl+Q | Quit |
